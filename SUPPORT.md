# Getting help

Thanks for using Untern's projects. Here is where to go:

| You want to… | Go to |
|---|---|
| Report a bug in one of our public repositories | Open an issue in that repository using the **Bug report** form |
| Suggest a feature or improvement | Open an issue using the **Feature request** form |
| Report a security vulnerability | **Do not open an issue.** Follow the [Security Policy](https://github.com/unternai/.github/blob/main/SECURITY.md) |
| Report a Code of Conduct concern | Email [conduct@untern.ai](mailto:conduct@untern.ai) |
| Get help with an Untern product or account | Email [support@untern.ai](mailto:support@untern.ai) or visit [untern.ai](https://untern.ai) |
| Anything else (partnerships, press, careers) | [untern.ai](https://untern.ai) |

GitHub issues are not monitored around the clock, and are best effort for open-source projects. Please do not
include secrets, API keys or personal data in issues.
